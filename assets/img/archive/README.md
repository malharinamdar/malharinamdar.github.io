# Archived images

Images that aren't currently referenced anywhere on the site, kept here to keep `assets/img/` tidy.

- **al-folio-defaults/** — placeholder and documentation images that shipped with the al-folio theme.
- **old-photos/** — older profile pictures and personal photos no longer used on the site.

Nothing in this folder is linked from any page. Move an image back up to `assets/img/` if you want to use it again.
